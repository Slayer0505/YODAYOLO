💡 What is YODA?
One Brain. Many AI Systems. Any Model.
YODA is an independent, persistent cognitive layer for your machine. Rather than locking memories and rules inside a single proprietary AI app or model, YODA sits at the center:
• AI Systems (Antigravity, OpenCode, Claude Code) are interchangeable tools you use.
• Reasoning Models (Claude 3.5, GPT-4o, Gemini 1.5 Pro, Local) are swappable engines.
• YODA Brain is the permanent cognitive memory that records evidence, learns rules, and carries knowledge between all of them.
When one AI tool fixes a test or learns a project constraint, YODA records the rule in L2 Knowledge and provides it to your next AI tool automatically.
ℹ️ Integration Compatibility Matrix
Directly Supported:
  • Local CLI agents & IDEs (Antigravity, OpenCode, Cursor, Aider)
  • Direct API endpoints (Anthropic Claude, OpenAI, Google Gemini)
  • Local reasoning engines (Embedded Reasoner, Ollama)
  • Custom programmatic pipelines via Universal REST API
Browser Web Chat Boundary:
Closed website chats (like chatgpt.com or claude.ai) run in sandboxed browser tabs that do not route through local sockets. They require a dedicated browser extension bridge to connect to YODA.
